# kapan-docs

Documentation, release notes and issue tracking for Portiger Kapan.

This repository is public so that documentation is readable and issues can be
filed without an account on our side. Product code lives in private
repositories.

When reporting a problem, please do not paste cluster names, image
references, policy contents, credentials or tokens into a public issue. For
security vulnerabilities use the disclosure process on the site rather than
the issue tracker.

Product site: https://kapan.portiger.com

## Türkçe

Portiger Kapan için dokümantasyon, sürüm notları ve hata takibi.

Bu depo, dokümantasyonun okunabilir olması ve bizim tarafımızda hesap
gerekmeden hata bildirilebilmesi için publictir. Ürün kodu private depolarda
durur.

Sorun bildirirken lütfen küme adlarını, imaj referanslarını, policy
içeriklerini, kimlik bilgilerini veya token'ları public bir issue'ya
yapıştırmayın. Güvenlik açıkları için hata takibi yerine sitedeki bildirim
sürecini kullanın.

Ürün sitesi: https://kapan.portiger.com
